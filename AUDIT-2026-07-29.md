## Three lead findings

**1. The constitution cites cost figures the fee model no longer produces.**
CLAUDE.md's scope rationale reads "a crypto round trip costs 50 bp against
1.14 to 4.87 bp for equities in the tradeable liquidity bands". Since the
2026-07-29 measurement, the fee model produces median round trips of about
17.8 bp (tier 3) and 41.2 bp (tier 4) for the band those figures describe.
The crypto-exclusion CONCLUSION stands, because the engine trades tier-1
names whose cost is unchanged at roughly 0.5 to 0.9 bp, but the cited number
is now false as a statement about the current model, and tier 4's 41.2 bp
sits within 20 percent of crypto's 50 bp, which weakens the rhetorical gap
the sentence relies on. Same class: PROGRESS.md's Current State still says
"`ctest` 7/7" against an actual 34 tests, and the "14 hard checks" claim
persists in CLAUDE.md and PROGRESS.md against 18 `fail(` sites in
`risk/risk_gate.cpp`. The prior audit flagged the 14-versus-18 gap two days
ago (AUDIT.md 4.4) and it survived. Documentation debt of this exact shape
has been the highest-yield audit finding three audits running.

**2. The direction of error moved.** The 2026-07-27 audit recorded that this
project errs toward under-claiming. This week produced two post-measurement
judgment calls that both landed in the permissive direction. First, the tick
measurement's pre-registered monotonicity check failed strictly (tick ladder
7.0 / 8.0 / 6.5 / 12.0, the script's own `usable` flag false) and the session
judged it near-monotone and wrote the values into the fee model. Second,
Amendment 5 moved the primary family from net to gross after the cost
measurement existed, which is precisely the moment such a change is most
tempting. Both calls are defensible on their merits and both were disclosed
with the counter-argument recorded, which is the discipline working. But both
moved the project toward proceeding, neither had an outcome-blind reviewer,
and the pattern deserves its name before it becomes a habit. The mitigation
that matters: Amendment 5's pre-registered verdict table is binding, and any
future softening of "a gross-positive net-negative result licenses no trade"
should be read as the failure mode this finding warns about.

**3. The amended primary has an uncontrolled confound a critical reader
attacks first.** The primary scores signed gross excess against the
equal-weighted band move. That construction cancels unconditional news-day
drift only if POSITIVE and NEGATIVE judgments are balanced. If the model
skews POSITIVE, say 70/30, and names in the news carry any unconditional
same-session attention premium over the quiet band, the pooled signed excess
inherits a fraction of that premium and reads as model skill. Nothing in the
specification controls for it: the benchmark is band-wide, not news-day
matched, and no shuffled-judgment null is registered. INFERRED, not measured:
stage 2's demonstration ran 37 next-open anchors against 12 same-close and
directional judgments were not balance-checked. A pre-registered
permutation control (re-run the primary with judgments shuffled within day,
report the null distribution) would close this cheaply and requires no new
data. Recorded here as a recommendation. This audit changes nothing.

## Task B — the fee model's two halves

**The agreement mechanism is sound at runtime and thinner at the defaults.**
Both halves read the same yaml at runtime: C++ through `config.cpp`
`get_double`, Python through the `fees.load()` regex. The measured values
therefore cannot diverge between languages while the yaml keys exist. The
mirror test (`test_every_new_key_exists_in_yaml_hpp_and_python`) pins all 18
liquidity keys present in the yaml, in `config.hpp`, and in the Python key
dict, and `test_the_python_and_cpp_tier_ladders_have_the_same_shape` pins the
six multiple keys plus the selector name in `core/fees.hpp`. A deleted or
renamed yaml key fails the mirror test. **What no test pins: value equality
between the yaml and the hard-coded fallback defaults** in `config.hpp` and
`fees.py`. Those defaults engage only when a yaml key is absent, which the
mirror test prevents for the shipped file, but a caller loading a DIFFERENT
yaml (an older config, a test fixture) falls to defaults silently, and the
two languages' defaults could in principle drift from each other. Today they
agree (1.0/1.0/8.0/9.0/1.0/1.0 in both). Low risk, named rather than fixed.

**Unmeasured tiers marked everywhere a reader would look: yes.** The yaml
comment block, `config.hpp`, `core/fees.hpp`, `backtest/fees.py` module
comment and function docstring, the pinning test's docstring, CONTEXT.md,
PROGRESS.md and EXPERIMENT.md all state that tiers 1, 2, 5, 6 are 1.0 floors
and unmeasured. Verified by reading each.

**One selector asymmetry, cosmetic:** C++ selects by `switch` on
`equity_liquidity_tier`, Python by f-string key construction. A seventh tier
added to one ladder and not the other would fail the shape test on the floors
but nothing pins the multiple-selector arity itself. Noted.

## Task C — the eighth fabrication

Searched every fallback and default in the collector, scoring, outcomes, fee
and measurement paths for a plausible value produced from absent input. **No
realized instance found.** The recent fixes hold: an unresolvable session
raises `UnknownSession`, a missing price is an exclusion rather than a roll
forward (`outcomes.py:134-137`), a missing bar source records `unclassified`,
a duplicate lands on `excluded_pre_call`, and the measurement script refuses
rather than sampling a feed it cannot trust. Three LATENT candidates, each
with the fabrication shape but no current trigger:

1. **`fees.equity_round_trip_bp` with `adv_usd <= 0` returns the flat 1.3 bp
   legacy figure** by documented design. In the ENGINE that fallback is
   deliberate and pinned by test. In the EXPERIMENT's scoring path
   (`outcomes.py:161`) the same fallback would cost a band symbol at 1.3 bp
   against a measured 17.8 to 41.2, silently inflating `net_bp` 14x to 40x,
   if `adv_usd_at_formation` ever arrived as 0 or NULL. Band membership
   guarantees ADV exists, so no current trigger, but the experiment path
   inherits an engine convenience whose failure direction is optimistic
   there. The honest behaviour for the E-tests would be to EXCLUDE a row
   whose ADV is absent, and that is a one-line precondition a future session
   could add under its own approval. Recorded, not fixed.
2. **`scoring.py:181-185` reads missing provider `usage` as zero tokens**, so
   a response without a usage block records zero cost in the spend ledger. A
   ceiling enforced against understated spend is a ceiling with a hole.
   Latent: Anthropic responses carry usage today.
3. **`fees.load()` returns the hard-coded default when its regex fails to
   match a key**, so a yaml value written in a form the pattern does not
   match (scientific notation, an inline comment before the number) would
   silently resurrect the stale default. The mirror test checks presence with
   its own regex of the same shape, so a matching failure would likely fail
   there too. Edge case, named.

1. **The near-monotone judgment (2026-07-29) is a post-data interpretation of
   a pre-registered check, in the permissive direction.** The registered
   wording allowed "near-monotone", so a judgment was always going to be

   the move. It is still the project's first instance of data being ruled
   usable after its own check flagged it, and lead finding 2 applies.
2. **Amendment 5 changed the primary's scored unit after cost data existed.**
   No outcome data existed, the change is disclosed, the counter-argument is
   recorded in the amendment, and the verdict table pre-commits the awkward
   outcome. The residual thinness: the strength secondaries' unit also moved
   (net to gross) citing consistency, which is a second post-registration
   change riding on the first, with less independent justification.
3. **Stage 1's model comparison remains unresolved and the chosen model was
   never compared to anything.** Amendment 3 says so honestly. The thinness
   is that collection can now start (stage 3 unblocked) with the capability
   question still open, and nothing in the specification forces it closed.
4. **The under-claiming pattern otherwise holds.** The tick session reported
   its strict check failure prominently, the fee update left tier-1 results
   untouched and proved it, and DATA_AUDIT's whale finding was adopted into
   the record without softening. No result was found reported more
   confidently than its method supports. No holdout was reused: the news
   experiment has no outcome data, and the price-research holdout was not

5. **Mutation tests were not re-run** (constraint: no test suite). One

## Task E — is the amended experiment sound

**The separation itself is sound.** Gross-signal and net-economics are
different questions, the conflation was real (half the band was
pre-condemned), the counter-argument is recorded, and the pre-registered
verdict table is the strongest guard in the document. The E-tests' per-stratum
floors and stated under-power are honest.

**What a critical reader attacks, in order:**

1. **The judgment-imbalance confound (lead finding 3).** The signed-excess
   construction cancels unconditional news-day drift only under balanced
   judgments. No shuffled-judgment null, no news-day-matched benchmark.
   Cheapest fix: pre-register a within-day judgment-permutation null before
   collection.
2. **A gross positive does not distinguish the model from a trivial reader.**
   The hypothesis names an LLM, but the primary would also clear for a
   keyword-sentiment rule if post-news drift exists at all, and the
   literature says it does. The specification tests "does this pipeline
   predict" and cannot attribute the prediction to model capability. The
   headline-type caveat (Amendment 3) concedes this for strength but the
   primary carries no baseline comparator. A finding, not a flaw in the
   test's own terms, but the conclusion must be worded as "the pipeline
   predicts", never "the model understands".
3. **Coverage selection.** Finnhub coverage correlates with liquidity and
   attention (stage 1: 18 of 50 S4 symbols silent, coverage concentrated in
   noisy names), so the scored sample is news-covered names, not the band.
   The result generalises to "names Finnhub covers", which is also the only
   population the system could trade. Stated in stage 1, worth restating in
   any conclusion.
4. **The 20-minute delay is untested against quote reality.** The delay
   answers latency, but no one has checked that the anchor price (next open
   or delayed close) is realizable against the measured spreads, and at S4's
   50 bp median the open print and the touch are far apart. The economic
   secondary inherits this: `cost_i` models the spread but the anchor price
   itself is a mid-family quantity. Adequate for gross, optimistic for net.
5. **What would make the result uninterpretable:** NEUTRAL above 80 percent
   (registered), strength degeneracy (registered, first look passed), rho
   above 0.05 without the registered recompute firing, judgment imbalance
   plus attention drift (unregistered, item 1), and a thin-strata cluster
   shortfall turning E3/E4 into abstentions (registered as abstention, which
   is the correct honest outcome).

**Net judgment: the amended specification is a sound test of "does this
pipeline's judgment carry directional information gross of cost", with one
registered-control gap (item 1) that should be closed before collection, and
correctly pre-commits itself against promoting an untradeable effect.**
